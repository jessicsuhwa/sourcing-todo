🔗 GitHub 저장소 연결

이 대시보드는 팀장님의 GitHub 저장소를 데이터베이스로 사용합니다. 아래 정보를 한 번만 입력하면, 이후 이 브라우저에 저장되어 다시 입력할 필요 없습니다.
GitHub → Settings → Developer settings → Personal access tokens에서 생성. 이 저장소에 대한 Contents 읽기/쓰기 권한만 있으면 됩니다. 토큰은 이 브라우저에만 저장되고 서버로 전송되지 않습니다.
직접 작성한 항목은 본인만 삭제할 수 있습니다. 이 브라우저에서 계속 이 이름으로 기록됩니다.
